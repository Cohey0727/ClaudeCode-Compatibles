# 2026-09-03 — pi ランチャー廃止とグローバル models.json 生成

`pi<name>` ランチャーを廃止した。OpenCode と同じく、pi はランチャーなしに
素の `pi` で使い、`make setup`（および単体の `make pi-global`）が全プロバイダ
入りの `~/.pi/agent/models.json` を生成する。pi 内の `/model` でどのプロバイダ
のモデルにも切り替えられ、そこで Ctrl+S を押すと起動時のデフォルトになる。

生成されたファイルにトークンは書かれない。各エントリの `apiKey` と
`HEADERS` の各値は `!` 付きのシェルコマンドで、pi がリクエスト時に
`providers/<name>/.env` から読み直す。`.env` が唯一の情報源で、トークンの
変更やコマンド置換 `$(...)` で計算するヘッダーは再実行なしで反映される。
モデルやエンドポイントを変えたときは `make pi-global` を再実行する。

`ARGS` / `CLAUDE_ARGS` は `claude<name>` だけに効く。`PI_COMMAND` と
`PI_ARGS` は意味を失ったので `.env.example` から消した（既存 `.env` に
残っていても無害）。`providers/<name>/.pi-agent/` は生成されなくなった。

## 手順

```bash
cd <repo>
git pull
make setup                    # .env の追従 + claude ランチャー再生成 + pi / OpenCode 設定生成
```

`make setup` は選択したプロバイダの旧 `pi<name>` ランチャーと `.pi-agent/`
を消す。選択しなかった分は `make uninstall` でも消えるし、手で消すなら:

```bash
rm -f ~/.local/bin/pideepseek ~/.local/bin/pimmx ~/.local/bin/piglm \
      ~/.local/bin/pikimi ~/.local/bin/pimimo ~/.local/bin/piox \
      ~/.local/bin/pilocal ~/.local/bin/pigtr
rm -rf <repo>/providers/*/.pi-agent
```

## 確認

```bash
head -1 ~/.pi/agent/models.json   # generated by claude-compatibles ... の行
pi                                # /model で切り替え
```
