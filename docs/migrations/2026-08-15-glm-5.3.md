# 2026-08-15 — GLM-5.3

Z.ai が GLM-5.3 を出したので `providers/glm/.env.example` を更新した。
既存マシンの `providers/glm/.env` は手で直す必要がある。

## 変更点

| 設定 | 旧 | 新 |
|---|---|---|
| `MODEL` | `glm-5.2` | `glm-5.3` |
| `SMALL_MODEL` | `glm-4.5-air` | `glm-4.7` |
| `SMALL_CONTEXT_WINDOW` | `131072` | `200000` |
| `SMALL_MAX_TOKENS` | `98304` | `131072` |

`CONTEXT_WINDOW=1000000` / `MAX_TOKENS=131072` は GLM-5.3 でもそのまま
（1M context / 128K output）。`glm-4.7` は 200K / 128K。

## 手順

`make setup` はキーが存在しない設定を追記するだけで、既存の値は書き換えない。
今回は 4 つとも既存キーなので、すべて手で直す。

```bash
cd <repo>
git pull

# providers/glm/.env を編集
#   MODEL=glm-5.3
#   SMALL_MODEL=glm-4.7
#   SMALL_CONTEXT_WINDOW=200000
#   SMALL_MAX_TOKENS=131072
```

`.env` を消して `make setup` で作り直し、`API_TOKEN` を貼り直しても同じ。
ランチャー自体は変わっていないので `make setup` の再実行は必須ではない。

## `[1m]` サフィックスは使わない

Z.ai の Claude Code 向けドキュメントは 1M コンテキストに `glm-5.3[1m]` を使えと
書いているが、これはコーディングプランのルート専用。`.env` の
`BASE_URL=https://api.z.ai/api/anthropic` に投げると
`[1214][modelCode: does not exist]` で 400 になる。素の `glm-5.3` がこのエンドポイント
では既に 1M なので、`CLAUDE_MODEL_SUFFIX` は空のままにする。

## 確認

```bash
piglm --list-models              # glm-5.3 と glm-4.7 が上限付きで出る
claudeglm -p "say ok"
```
